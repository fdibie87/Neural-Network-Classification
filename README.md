# MNIST Image Classification Using Artificial Neural Networks

# Project Overview
This project explores artificial neural networks for handwritten digit classification using the MNIST dataset. Multiple neural network configurations were trained and evaluated to compare their performance.

# Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- MLflow
- DagsHub
- Jupyter Notebook

# Project Objectives
- Build and train neural networks for image classification.
- Experiment with different model architectures and hyperparameters.
- Compare training and validation performance.
- Track experiments using MLflow and DagsHub.

# Results
The best recorded validation accuracy was approximately 98.24%.
